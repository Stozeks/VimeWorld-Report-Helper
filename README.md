# VimeWorld Report Helper

**VimeWorld Report Helper (VRH)** — браузерное расширение для улучшения интерфейса и ускорения работы с системой репортов VimeWorld.

Расширение добавляет дополнительный интерфейс поверх существующей страницы модерации и предоставляет инструменты для более удобной обработки репортов.

> Проект находится в активной разработке.

---

## ✨ Возможности

### 📋 Report Helper

Дополнительная панель для работы с открытым репортом:

- автоматическое определение текущего репорта;
- отображение ID репорта;
- отображение нарушителя;
- количество сообщений;
- быстрый выбор причины;
- автоматический расчёт времени наказания;
- копирование подготовленных данных;
- сброс выбранной причины.

### ⚡ Быстрый выбор нарушений

Причины нарушений представлены в виде отдельных интерактивных плиток.

Это позволяет значительно быстрее выбирать нужную причину без ручного ввода текста.

Причины с более серьёзными последствиями визуально выделены отдельно.

### 🔎 Сканирование репорта

VRH содержит систему анализа сообщений открытого репорта.

Она предназначена для поиска потенциальных нарушений и помощи модератору при просмотре истории сообщений.

Результат сканирования является вспомогательным и не заменяет решение модератора.

### 📊 Локальная статистика

Расширение ведёт локальную статистику работы:

- количество закрытых репортов;
- количество отклонённых репортов;
- общее количество обработанных репортов;
- система баллов;
- статистика за текущий месяц.

Все данные хранятся локально в браузере.

### ↩️ Reason Undo

Система восстановления предыдущего выбранного решения позволяет быстрее исправлять случайные действия во время обработки репорта.

### 🌐 Текстовые инструменты

В панель встроены дополнительные инструменты для работы с текстом:

- `English → Russian`
- `Russian → English`

---

## 🎨 Интерфейс

VRH использует собственный интерфейс, визуально интегрированный со страницей VimeWorld Reports.

В проект также входит отдельная тема страницы:

- тёмная цветовая схема;
- новый фон;
- переработанные элементы интерфейса;
- визуальное разделение типов нарушений;
- компактная панель инструментов.

### DOM Adapter

`dom-adapter.js` является отдельным слоем взаимодействия с DOM страницы VimeWorld.

Это уменьшает зависимость остальных модулей от конкретной HTML-структуры сайта и упрощает адаптацию расширения при изменениях интерфейса VimeWorld.

## 🔒 Конфиденциальность

VimeWorld Report Helper работает локально в браузере.

Проект не предназначен для:

- сбора пользовательских данных;
- отправки статистики на сторонние серверы;
- сторонней аналитики;
- хранения паролей или токенов.

Локальная статистика VRH хранится на устройстве пользователя.

---

## ⚠️ Важно

VimeWorld Report Helper является вспомогательным инструментом.

Расширение не должно самостоятельно принимать модераторские решения.

Финальное решение по репорту и применению наказания всегда остаётся за модератором.
